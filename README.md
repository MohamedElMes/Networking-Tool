# Networking Tool

## Description

This Networking Tools is composed of multiple options helpful in networking, like sending ping paquets or a tracert for example. All the results of using those command will al be stored in logfiles so anyone can go back and save the results.
It aims to help anyone and centralise core networking tools into one single tool.

## Installation

### Windows

Open a Shell and use the ``wsl`` command to create a Linux subsystem. Chose whatever distro you want. In my case im using a Debian subsystem for the tests.
```
git clone https://github.com/MohamedElMes/Networking-Tool/
```

### Linux

```
git clone https://github.com/MohamedElMes/Networking-Tool/
```
